ℹ Méthodes, formules et conventions

Conventions

• X = Est, Y = Nord : ΔX = d·sin(G), ΔY = d·cos(G).

• Gisement : angle horaire compté depuis le Nord (Y), croissant de 0 à 400 gon (360°).

• Toutes les distances sont supposées horizontales. Les angles saisis sont horizontaux.

• Unité par défaut : le grade (gon). Modifiable en haut de page ; toutes les saisies s'interprètent alors en degrés.

Gisement et problème direct/inverse

GAB = atan2(ΔX, ΔY) ; dAB = √(ΔX² + ΔY²). Problème direct : XB = XA + d·sin(G), YB = YA + d·cos(G).

Cheminement d'ensemble (polygonale)

Angle à droite : Gi = Gi−1 + 200 + αi (gon) ; angle à gauche : Gi = Gi−1 + 200 − αi.

Fermée : Σα devrait valoir (n−2)×200 gon (angles à droite, n sommets) ; l'écart w est réparti également sur tous les angles.

Encadrée : w = Gfinal calculé − Gfinal connu, réparti sur le nombre d'angles.

Fermeture planimétrique : fa = √(fx² + fy²) ; précision = Σd / fa (1/ …).

Bowditch : correction ΔXi = −fx·di/Σd (idem ΔY) ; Transit : correction ΔXi = −fx·|ΔXi|/Σ|ΔX|.

Intersection – recoupement

Intersection : résolution de P = A + t·uGa (droites par gisements depuis 2 stations connues).

Recoupement : angles α (à A, entre la base AB et AP) et β (à B, entre BA et BP, horaires) ; GAP = GAB + α, GBP = GBA − β, puis intersection des deux directions.

Nivellement direct

Δh = AR − AV pour chaque cheminement partiel ; altitude cumulée station par station ; la fermeture est corrigée proportionnellement au nombre de cheminements.

Surface (Gauss)

S = ½ · |Σ (Xi·Yi+1 − Xi+1·Yi)| ; centroïde par la formule classique du polygone.
